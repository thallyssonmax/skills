# Fontes para Projetos do ChatGPT

Área opcional para arquivos `<nome-da-skill>-context.md`, quando uma skill pessoal precisar ser disponibilizada como contexto em um Projeto do ChatGPT.

Os arquivos aqui são referências de projeto, não instalações nativas de skills. Mantenha-os alinhados ao SKILL.md correspondente; ao atualizar no GitHub, substitua também as fontes previamente carregadas no ChatGPT.
