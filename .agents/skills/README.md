# Skills pessoais

Coloque cada futura skill em uma pasta própria: `.agents/skills/<nome-da-skill>/SKILL.md`.

Não crie pastas de skills sem conteúdo real. Use `references/`, `scripts/` e `assets/` somente quando necessário.

Para Codex, este diretório pode ser usado diretamente ao abrir o repositório, ou cada pasta pode ser instalada em `~/.agents/skills/` para uso global.
